What it does

Takes a capture, encrypts the words and the place with a key derived from your passphrase, and searches only in memory after you unlock. The stored bytes hold no word you typed.

What it refuses

An unreadable store is never replaced with an empty one, and a broken key is never mistaken for a new install.
